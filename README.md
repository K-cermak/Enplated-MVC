### 👍 Why use Enplated MVC?
- <b>Simple MVC PHP framework</b> focused on speed and simplicity.
- <b>Template files</b> inspired by Laravel Blade.
- <b>Amazing routing</b> with <b>URL parameters</b> support.
- <b>Doesn't use Composer</b> or any other external libraries. Just pure PHP.
- Integrated <b>debugger</b>, supports PHP 5.6 to 8.x.

### 🤔 FAQ

#### Which PHP versions are supported?
- ✅ 8.x - supported.
- ✅ 7.x - supported, consider upgrading to PHP >=8.4.
- ☑️ 5.6 - working, not recommended, support will be dropped when PHP 9 is released.
- ❗ <5.6 - unsupported, does not work.
<br/><br/>
- Tested in PHP 5.6.40, 7.0.33, 7.1.33, 7.2.33, 7.3.32, 7.4.33, 8.0.26, 8.1.28, 8.2.19, 8.3.7.

#### Which web servers are supported?
- Currently, only Apache is officially supported. However, if you replicate the .htaccess rules on another server (e.g. NGINX), it will work as well.

#### How would you compare Enplated MVC with other frameworks? What are the differences compared to Laravel?
- Enplated MVC clearly doesn't offer as many features as other major frameworks. For example, it has only limited support for testing, automated deployment, and similar tooling.

- However, large frameworks are often unnecessarily complex. Here is a comparison of similar applications written in Enplated MVC and Laravel:

|                  | **Enplated MVC**         | **Laravel**                |
|------------------|--------------------------|----------------------------|
| **Load Time**    | ≈10 ms 👌                   | ≈200 ms 😭                   |
| **Size**         | 340 KB 👌                   | 49.3 MB 👎                   |
| **Number of Files** | 48 👌                   | 4589 🤷                      |
| **Supported DB** | MariaDB, MySQL, SQLite 👍   | MariaDB, MySQL, SQLite, PostgreSQL, SQL Server 👌 |

- Laravel is suitable for huge projects with dozens of people working on them. Enplated MVC is suitable for small to medium-sized projects, and although it doesn't offer the same features as Laravel, it is much faster, smaller, and more intuitive.

#### Is Enplated MVC based on OOP?

- No, the entire core of Enplated MVC is written procedurally. This is mainly for speed, as OOP would make the core slower.

- However, controllers and models use techniques that make your code feel almost object-oriented, so you can approach it much like an OOP project.

#### What are the future plans for Enplated MVC?

- **In future versions we want to focus on the following aspects:**
    - Extending the functionality of the template engine.
    - Better debugging capabilities.
    - Adding middleware and extending authentication features.
    - Adding caching capabilities.
    - Better optimization techniques in routing.

- **On the other hand, we want to avoid:**

    - Moving to OOP.
    - Using NPM, Composer, etc.
    - Prioritizing the number of features over speed.
